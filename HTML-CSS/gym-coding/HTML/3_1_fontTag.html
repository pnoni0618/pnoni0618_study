김치볶음밥

김치를 주 재료로 사용한 볶음밥이다.
주 재료가 사기적인 감칠맛 덩어리인 김치라
요리 실력이 조금만 받쳐준다면 낼 수 있는 맛의 저점이 높지만,
들어가는 재료가 한정적이라 특색있게 만들기는 의외로 어려운 요리이다.
