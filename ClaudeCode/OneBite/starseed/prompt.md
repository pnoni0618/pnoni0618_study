# 프로젝트

웹 페이지 하나를 만들어줘.

서비스 이름은 아래 둘 중 하나의 분위기로 디자인해줘.

- **Starseed Origin**
- **나는 어느 별에서 왔을까?**

부제목

> 당신의 성향을 분석하여 가장 닮은 스타시드를 찾아드립니다.

이 서비스는 재미와 자기 탐색을 위한 심리·성향 테스트이며,
영성과 우주를 좋아하는 사람들이 몰입할 수 있는 분위기로 제작해줘.

실제로 어느 별에서 왔는지를 증명하는 서비스가 아니라,
사용자의 성향을 분석하여 가장 닮은 스타시드 유형을 알려주는 서비스이다.

# 전체 컨셉

전체적인 분위기는

- 신비롭고 몽환적인 우주
- 은하수
- 별빛
- 성운(Nebula)
- 오로라
- 황금빛 입자 효과
- 잔잔하게 움직이는 별 애니메이션
- 유리(Glassmorphism) UI
- 현대적인 감성

을 조합한 프리미엄 디자인으로 만들어줘.

저렴한 느낌이나 어린이 사이트처럼 만들지 말고

Apple + 우주 + 영성

느낌의 고급스러운 UI를 만들어줘.
